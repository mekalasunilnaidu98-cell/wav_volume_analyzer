# WAV volume analyzer

A small, standalone Python 3 project for text or speech analysis. It uses only the Python standard library; no installation is required.

## Run

```bash
python main.py input.wav
```

## Input

Use a UTF-8 text file for transcript/text projects. Audio projects accept uncompressed PCM WAV files; check each script's usage message for format requirements.

## Notes

These projects are educational baselines. Rule-based outputs should be reviewed before using them for high-stakes moderation, hiring, medical, legal, or similar decisions.
